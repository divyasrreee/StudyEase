# StudyEase – Adaptive Personal Study Planner

StudyEase is an adaptive personal study planner designed to help students organize their subjects, manage study sessions, and plan their learning activities effectively.

## 🚀 Project Overview

StudyEase provides a centralized platform for students to manage their academic schedules, prioritize subjects, and track their study activities. The application aims to improve productivity through structured study planning and better time management.

## ✨ Features

- **Subject Management** – Organize subjects and assign importance levels.
- **Study Session Management** – Create and manage study sessions.
- **Personalized Study Planning** – Plan study activities based on academic priorities.
- **Student Management** – Manage student-related information.
- **Interactive User Interface** – Simple and user-friendly frontend.
- **Backend Integration** – Connect frontend functionality with backend services.
- **Database Support** – Store and manage application data using MySQL.

## ⚙️ Setup and Installation

### Prerequisites
- Java JDK
- Maven
- MySQL
- Visual Studio Code
- Web Browser

### Steps to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/divyasrreee/StudyEase.git
   ```

2. Open the project in Visual Studio Code.

3. Configure your MySQL database and update the backend database settings.

4. Navigate to the backend directory:

   ```bash
   cd backend
   ```

5. Run the Spring Boot application:

   ```bash
   .\mvnw.cmd spring-boot:run
   ```

6. Open `frontend/index.html` using Live Server in VS Code.
